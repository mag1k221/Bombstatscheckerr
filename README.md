# Boomsquad Stats

Paste an AlbionBB battle link (single or multi-battle) + a .txt with your squad's names → summed kills, deaths, K/D, IP, kill fame and comp.

- `index.html`, `app.js`, `style.css`, `assets/` – the site
- `api/stats.js` – Vercel serverless function (AlbionBB API, fallback: official Albion API)
- `dev-server.mjs` – local preview: `node dev-server.mjs` → http://localhost:3000
